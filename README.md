# City cheated to catch up

A static visual essay about Manchester City's revenue, disguised owner funding and football's financial rules. The article contains its sources, methodology and case-status date.

## Local preview

No build step or package installation is required:

```sh
python3 -m http.server 8765
```

Open http://localhost:8765 in a browser.

## Files

- `index.html`: narrative, source references and page structure
- `data.js`: revenue and identified owner-funding figures
- `story.js`: charts, calculations and responsive chapter behaviour
- `styles.css`: typography and layout

## Publishing

GitHub Pages serves the repository root from `main`. Push changes to `main` to update the site. `.nojekyll` keeps the files as a plain static site.
